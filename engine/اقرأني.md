# النسخة المصححة

ابدأ بملف README.md للأوامر والافتراضات والمراجع. الملفان الرئيسيان nca.py وbioequivalence.py يحتاجان إلى _common.py الموجود في المجلد نفسه، وإلى NumPy وSciPy.

صُححت معادلة RSABE، وفُصل التصميم المكرّر الجزئي عن الكامل في حساب القوة، وأضيف تحقق صارم من التسلسل والفترة والبيانات. تحليل EMA ABEL منفصل عن تحليل FDA، وتقدير تباين المرجع يصحح أثر الفترة بحسب طريقة التحليل.

هذه نسخة للبحث والتعليم ذات اختبارات مرفقة، تُقدَّم «كما هي» بلا أي ضمان؛ ليست برنامجًا معتمدًا لملف تنظيمي (لا تحقق وفق GAMP 5، ولا مقارنة مع WinNonlin، ولا اختبار على دراسة حقيقية). تقبل التصاميم القياسية؛ والبيانات الناقصة (فترات مفقودة) تُحلَّل بنموذج التأثيرات الثابتة (طريقة EMA A) وABEL وإطار SFDA، بينما يتطلب تحليل فروق الأفراد وRSABE وطريقة FDA للأدوية ضيقة المؤشر مشاركين مكتملين. في مقارنات التصاميم متعددة المعالجات وفي 2×2 بنموذج التأثيرات الثابتة، يُستبعد من لا يملك بيانات للمستحضرين معًا ويُدرج في جدول (ICH M13A 2.2.3.2). حساب القوة متاح لـ ABE ذي الحدود الثابتة، ولا يحسب قوة RSABE أو ABEL. خيار NTI يضيّق الحدود فقط. مسار FDA غير المتدرج عند انخفاض تباين المرجع غير منفذ، ويصدر البرنامج خطأً صريحًا بدل إعطاء حكم مضلل.

مثال حساب قوة التصميم الجزئي:

```bash
python bioequivalence.py --power --design partial --cv .30 --gmr .95 --n 24 --format json
```

لتشغيل الاختبارات:

```bash
python -m unittest -v
python validate_simulation.py
```

ملف example_partial.csv بيانات مولدة لغرض الاختبار، وليس دراسة حقيقية. قورن nca.py بحزمة PKNCA 0.12.1 وتحليل ABEL بحزمة replicateBE 1.1.3 وبنتائج EMA المنشورة لمجموعتيها المرجعيتين (مجلد validation)، ولم تُجر مقارنة مع SAS أو WinNonlin، ولم يُختبر البرنامج على دراسة سريرية حقيقية.
