# النسخة المصححة

ابدأ بملف README.md للأوامر والافتراضات والمراجع. الملف الرئيسي bioequivalence.py يحتاج إلى _common.py الموجود في المجلد نفسه، وإلى NumPy وSciPy.

صُححت معادلة RSABE، وفُصل التصميم المكرّر الجزئي عن الكامل في حساب القوة، وأضيف تحقق صارم من التسلسل والفترة والبيانات. تحليل EMA ABEL منفصل عن تحليل FDA، وتقدير تباين المرجع يصحح أثر الفترة بحسب طريقة التحليل.

هذه نسخة بحثية ذات اختبارات مرفقة؛ ليست برنامجًا معتمدًا لملف تنظيمي. تقبل التصاميم المحددة المكتملة فقط. حساب القوة متاح لـ ABE ذي الحدود الثابتة، ولا يحسب قوة RSABE أو ABEL. خيار NTI يضيّق الحدود فقط. مسار FDA غير المتدرج عند انخفاض تباين المرجع غير منفذ، ويصدر البرنامج خطأً صريحًا بدل إعطاء حكم مضلل.

مثال حساب قوة التصميم الجزئي:

```bash
python bioequivalence.py --power --design partial --cv .30 --gmr .95 --n 24 --format json
```

لتشغيل الاختبارات:

```bash
python -m unittest -v
python validate_simulation.py
```

ملف example_partial.csv بيانات مولدة لغرض الاختبار، وليس دراسة حقيقية. لم تُجر مقارنة تنفيذية مستقلة مع SAS أو حزم R، ولم يُختبر البرنامج على دراسة سريرية حقيقية.
